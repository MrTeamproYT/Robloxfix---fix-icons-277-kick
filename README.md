# Robloxfix---fix-icons-277-kick
# RobloxFixer — починка Roblox (ошибка 277 + не грузятся иконки)

Один `.bat`-файл, который автоматически находит и удаляет причину **ошибки 277** и **не загружающихся иконок/превью** в Roblox на Windows.

> **В чём суть:** многие «ускорители» и обходилки DPI (Zapret / GoodbyeDPI / ByeDPI и т.п.) ставят в Windows **службу**, которая при каждой загрузке ПК запускает `winws.exe`. Она перехватывает трафик на портах `80/443/8443` и игровом UDP, из-за чего Roblox **кикает с ошибкой 277** на некоторых серверах. Параллельно ломается DNS на порту 53 — и перестают грузиться иконки игр/аватарок.

---

## Симптомы

- Ошибка **277** при входе на часть плейсов/серверов (на другие заходит нормально)
- **Не грузятся иконки** игр, превью, аватарки (серые квадраты)
- В логах Roblox: `Could not resolve host: tr.rbxcdn.com`, `HttpError: DnsResolve`

## Причина

| Что установлено | Что делает | Итог |
|---|---|---|
| Служба `zapret` (автозапуск) | запускает `winws.exe` + драйвер `WinDivert` | перехват пакетов → **277** |
| `winws` / GoodbyeDPI | подмена TCP/UDP на 80,443,8443 | рвёт соединение с сервером |
| Happ / BestProxyVPN / Radmin VPN | прокси и виртуальные адаптеры | нестабильность, конфликты |
| Перехват DNS (порт 53) | режет цепочку `tr.rbxcdn.com` | **не грузятся иконки** |

Доказательство: DoH (порт 443) отдаёт рабочий IP и картинку `HTTP 200`, а обычный DNS на порту 53 — обрезанная цепочка и `NXDOMAIN`. То есть ломается именно порт 53, а не сам CDN.

## Использование

1. Скачай **`RobloxFixer.bat`**
2. **Правый кнопкой → «Запуск от имени администратора»** → согласись в UAC
3. Дождись отчёта `[OK]` / `[FAIL]`
4. **Перезагрузи компьютер**
5. Запусти Roblox

Файл самодостаточный: не требует установки, Python, PowerShell-модулей. Работает на **Windows 10 и 11**.

---

## Что делает скрипт

1. **Находит и удаляет все службы**, запускающие `winws` / `zapret` / `WinDivert` (сканирует службы по содержимому `ImagePath`, а не по имени — работает даже если служба называется иначе)
2. **Убивает перехватчики**: `winws`, `happd`, `BestProxyVPN`, ExitLag, Mudfish, GoodbyeDPI; отключает службы Happ / Radmin; выгружает драйвер `WinDivert`
3. **Чистит остатки прокси** в реестре
4. **Очищает кэш Roblox**
5. **Ставит DoH DNS** (Cloudflare `1.1.1.1`) — сам определяет реальную сетевую карту, пропуская VPN/виртуальные адаптеры
6. **Чинит иконки**: если `tr.rbxcdn.com` не резолвится — берёт рабочий IP через DoH, **проверяет его реальным запросом картинки** и вписывает в `hosts`
7. **Сбрасывает DNS-кэш и Winsock**, затем печатает **отчёт PASS/FAIL** по каждой проверке

Всё определяется динамически: имена адаптеров, пути Roblox, наличие/отсутствие Zapret. На чистом ПК лишние шаги просто пропускаются.

---

## Проверка после запуска

Скрипт выводит чек-лист:

```
[OK] All interceptor processes stopped
[OK] No zapret/winws service
[OK] WinDivert driver not active
[OK] tr.rbxcdn.com resolves -> icons will load
```

Если везде `[OK]` — ошибка 277 устранена.

---

## ⚠️ Важно

> **Не запускай `service.bat` / `general.bat` из папок Zapret, пока играешь в Roblox.** Они заново установят службу, и ошибка 277 вернётся.

Если Zapret тебе нужен для Discord/Google — запускай его **только вне игры**, либо добавь `roblox.com` и `rbxcdn.com` в список исключений Zapret (`list-exclude.txt`).

## Ручной разбор (без скрипта)

<details>
<summary>Как починить вручную</summary>

**1. Удалить службу Zapret (нужен CMD от администратора):**
```bat
sc stop zapret
sc delete zapret
taskkill /F /IM winws.exe
sc stop WinDivert
sc delete WinDivert
```

**2. Отключить прочие перехватчики:**
```bat
sc stop HappService & sc config HappService start= disabled
sc stop RvControlSvc & sc config RvControlSvc start= disabled
```

**3. Сбросить сеть и DNS:**
```bat
ipconfig /flushdns
netsh winsock reset
```

**4. Чинка иконок.** Пропиши рабочий IP в `C:\Windows\System32\drivers\etc\hosts`:
```
108.157.214.52  tr.rbxcdn.com
```
(IP проверить: `curl --resolve "tr.rbxcdn.com:443:<IP>" https://tr.rbxcdn.com/...` должен вернуть `200`)

**5. Перезагрузка ПК.**

</details>
